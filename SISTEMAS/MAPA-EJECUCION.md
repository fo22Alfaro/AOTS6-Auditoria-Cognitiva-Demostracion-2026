# MAPA DE EJECUCIÓN POR FORO

| Hecho | Foro | Instrumento |
|-------|------|-------------|
| Copia / usurpación de obra en México | INDAUTOR + vía civil / IMPI (infracción) | CESE-Y-DESISTIR + registro |
| Secreto industrial / marca / patente | IMPI | solo si hay activo concreto |
| Hosting en GitHub / plataformas US | Notice DMCA al host | prueba de titularidad + LICENSE |
| Infracción en otro país Berna | Tribunales / oficina de ese país | trato nacional + prueba de fijación |
| Práctica anticompetitiva | CNA (LFCE, Art. 28 CPEUM) | PLANTILLA-HECHOS-CNA completa |
| Incumplimiento de licencia firmada | Tribunal pactado en el contrato | LICENCIA-ESCRITA |
| Prueba en el extranjero | Asistencia jurídica mutua / apostilla | acta notarial + hashes |

## Regla de disparo
1. Notificar (cese).
2. Si no cesa: foro del daño + el de mayor eficacia probatoria.
3. No mezclar antitrust con IP salvo que existan **ambos** conjuntos de hechos.

## Lo que este mapa implementa
Cobertura multi-foro. No un tribunal mundial. Sí un **sistema de disparo** para no dejar brechas sin vía.
