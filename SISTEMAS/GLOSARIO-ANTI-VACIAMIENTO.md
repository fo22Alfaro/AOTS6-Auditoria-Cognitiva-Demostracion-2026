# GLOSARIO ANTI-VACIAMIENTO · AOTS⁶ · ARR-2.0

Cada término anglosajón se **define** aquí para que no vacíe el derecho moral mexicano. La glosa no es permiso.

| Término | Lo que pretenden | Lo que es, bajo este marco |
|---------|-----------------|---------------------------|
| *copyright* | Derecho de copia negociable | Glosa de *derecho de autor* (moral + patrimonial); no lo sustituye |
| *work made for hire* | El patrón es «autor» | Inoponible; LFDA 18: el creador es primigenio |
| *fair use* / *fair dealing* | Permiso elástico | **No** es licencia sobre esta obra |
| *transformative* | «Transformé, luego es mío» | Transformar sin escrito = infracción |
| *idea / expression* | «Era una idea» | Lo fijado (texto, código, hashes, nomenclatura) es **expresión** |
| *implied license* | «Al publicar, aceptaste» | Falso; ARR-2.0 en la raíz |
| *browsewrap* / *clickwrap* | ToS = cesión | Inoponible al autor respecto de esta obra |
| *safe harbor* | El host «no sabe» | Defensa del host **hasta** el notice; tras notice, se cierra |
| *public domain* / *open* | «Todo es de todos» | Esta obra **no** lo es |
| *TDM* / *AI training* / *non-expressive* | Minar/entrenar no es uso | Es uso; prohibido sin escrito |
| *research* / *academic* / *non-commercial* | Excepción automática | No equivalen a licencia |
| *willful* | «No sabía» | Quien ve LICENSE + NOTICE + este glosario y usa igual, usa a sabiendas |
| *statutory damages* | Solo en foros que los den | No crea ni borra el derecho moral |
| *peer review* / *priority* | Solo existe quien publica en el club | La fijación (21/03/2025) es la prioridad; el club no la otorga |
| *transformative AI* | El modelo «crea» | El modelo copia a escala; la expresión sigue siendo del autor |

**Regla:** si un término no está en esta tabla, se lee como glosa y se interpreta a favor del autor (LICENSE §0.4).
