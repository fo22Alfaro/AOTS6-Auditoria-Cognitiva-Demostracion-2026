# CHECKLIST INDAUTOR — OBRA HUMANA ORIGINAL

Objetivo: registro de obra científica / software / documentación de **autoría humana**.  
Las obras generadas exclusivamente por IA no son registrables (criterio SCJN / INDAUTOR).

## Documentos
- [ ] Identificación oficial del autor
- [ ] Formato RPDA-01 (o vía vigente: físico / correo si INDARELIN sigue suspendido)
- [ ] Ejemplar de la obra (PDF consolidado del expediente + descripción del software)
- [ ] Declaración de autoría humana y originalidad
- [ ] LICENSE ARR y NOTICE
- [ ] SHA del commit y URL del repo (anexo)
- [ ] Comprobante de pago de derechos

## Contenido a registrar (sugerido)
Manifiestos, ecuaciones fijadas como texto, documentación, código si existe, marco legal, protocolos.  
Registrar la **expresión**, no “la idea del universo”.

## Después del acuse
- Conservar número de registro y ejemplares.
- Anexar el acuse al expediente notarial.
- Actualizar NOTICE con número de registro cuando exista.
