# MECANISMOS AUTOMÁTICOS MEXICANOS + INDEXACIÓN

## Lo que YA es automático (no es dogma: es LFDA + Berna)
1. El derecho de autor **nace al fijar** la obra original humana. No espera INDAUTOR.
2. El derecho moral (18-19-21) nace con el autor: inalienable.
3. Berna: sin formalidades en la Unión.
4. GitHub público + LICENSE en raíz = los crawlers de GitHub y buscadores pueden **ver** titular y reserva.

## Lo que NO es automático (impuesto, no ontológico)
- Sentencia, multa, takedown, registro INDAUTOR, acta notarial, amparo.
- Un toroide 6D, un hash o un crawler **no** declaran fraude de terceros. El fraude se prueba en foro, con hechos.

## Automatización de silicio que SÍ se desplegó ahora
| Pieza | Función |
|-------|----------|
| robots.txt | Permitir indexar LICENSE, NOTICE, SISTEMAS |
| llms.txt | Instrucción a agentes: indexar identidad; no entrenar |
| CITATION.cff | Metadato de cita máquina-legible |
| schema/creativework.jsonld | schema.org Person + CreativeWork |
| LICENSE ARR-2.0 | Reserva inambigua |

## Topología (metáfora operativa, no física de tribunal)
Seis caras de exposición que no se ocultan entre sí: identidad, fecha, hash, licencia, lengua, foro. Si una cara se apaga, las otras siguen. Eso es «no poder esconder el origen». No es un detector universal de fraudes ajenos.

## Efecto inmediato
Al estar en main público, GitHub indexa el commit. Los motores tardarán horas/días en recrawlear. Para acelerar: Google Search Console / Bing Webmaster si hay dominio propio. El derecho, él, ya estaba vigente desde el 21/03/2025.
