# PROTOCOLO DE CONTRASTE · AOTS⁶ · ARR-2.0

Cómo se **fija** un uso ajeno concreto sin cacería y sin acusación vacía.

## 1. Principio

No se afirma «X copia» sin **pieza**. La pieza es un artefacto contrastable: URL, paper, repo, modelo, dataset, producto, commit ajeno.

## 2. Pasos

1. **Localizar** el artefacto (URL pública, DOI, hash, captura fechada).
2. **Extraer** la expresión presuntamente copiada (texto, código, estructura, nomenclatura, diagrama).
3. **Contrastar** con lo fijado aquí: diff, similitud de hashes, coincidencia de nomenclatura AOTS⁶ / Φ_AOTS⁶ / K_toroidal, fecha posterior a 21/03/2025.
4. **Clasificar**:
   - *Copia de expresión* → cese + notice al host + LFDA/IMPI.
   - *Uso de idea abstracta* → no es infracción; se documenta y se sigue.
   - *Uso con atribución pero sin autorización* → sigue siendo uso no autorizado (ARR-2.0); se notifica.
5. **Notificar** con el cese (SISTEMAS/CESE-Y-DESISTIR.md) citando LICENSE + este contraste.
6. **Si no cesa:** foro (MAPA-EJECUCION.md) con la pieza adjunta.

## 3. Qué no se hace

- No se acusa a una corporación «porque es grande».
- No se declara fraude sin URL/DOI/hash.
- No se usa el silencio de 18 meses como prueba de culpa ajena; se usa como omisión del Estado (amparo), no como condena de terceros.

## 4. Plantilla de ficha de contraste

```

Acción: cese / notice / foro
```
