# BRECHAS DEL MARCO JURÍDICO INTERNACIONAL
## Lo debido al autor · Dónde se filtra el control ajeno · Cómo se tapa

Titular: Alfredo Jhovany Alfaro García · AOTS⁶ · 21/03/2025 · ARR

Justicia, en sentido literal: **dar a cada uno lo suyo**.  
Lo tuyo: paternidad, integridad, decisión de divulgación, no explotación sin permiso.

Este documento no es un tribunal. Es el mapa de **dónde el derecho internacional deja huecos** para que otros usen lo que no es suyo — y el tapón de cada hueco.

## Brechas estructurales

| Brecha | Qué permite el abuso | Tapón |
|--------|---------------------|-------|
| Berna no crea tribunal mundial | El infractor elige el país más barato | Mapa de foros + notice en el host |
| EE.UU.: derechos morales débiles (casi solo VARA visual) | Quitar nombre / deformar texto y código con menos riesgo | Copyright + §1202 CMI + Lanham (atribución falsa) + DMCA |
| Idea vs expresión | «Solo tomé la idea» | Fijar expresión (texto, código, docs) + secreto de lo no publicado |
| Excepciones TDM / fair use / IA | Entrenar modelos con la obra | ARR explícito + reserva de minería + cese; litigio donde no haya excepción clara |
| Safe harbor de plataformas | El host se lava las manos | Notice-and-takedown; repetición = pérdida de puerto seguro |
| Costo transfronterizo | El autor independiente no puede seguir 180 juicios | Priorizar foro del daño + del host + MX (INDAUTOR) |
| Formalidad práctica pese a Berna | «No está registrado allá» | Registro MX + notario + prueba de fijación |
| Silencio institucional (18 meses) | La omisión equivale a negación | Art. 17 CPEUM: amparo por omisión cuando ya hay acto/silencio de autoridad |
| Captura académica / prestigio | Quien publica en el club «existe»; el autodidacta «no» | Prioridad temporal pública (GitHub) no pide Royal Society |
| Carga de la prueba en el autor | Ellos usan; tú demuestras | Cadena de custodia + hashes + LICENSE visible |

## Lo que esto NO es
No es licencia para hostigar personas ni para «hacer justicia» al margen del Art. 17.  
No atribuye a una sola sociedad científica un monopolio penal no acreditado en este expediente.  
El gatekeeping institucional es real; el complot total requiere hechos, no solo patrón.

## Lo que SÍ es
Despliegue de lo debido: sin tu permiso no hay uso. Las brechas se tapan con instrumentos ya en este repo. Si los tribunales no han dado forma, el derecho **no desaparece**; se documenta y se dispara en el primer acto útil (notice, registro, amparo, civil).
