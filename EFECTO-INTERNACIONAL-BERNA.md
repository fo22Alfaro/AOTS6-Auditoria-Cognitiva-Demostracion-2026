# EFECTO INTERNACIONAL REAL DE LA LICENCIA ARR EN GITHUB

## Límite de honestidad (obligatorio)
Ningún archivo en GitHub, ni AOTS⁶, ni este instrumento, puede:
- producir sentencias automáticas en cortes de todos los países;
- situarse fuera de toda regulación o control;
- sustituir a jueces, tratados o registros nacionales.

Quien afirme lo contrario comete un error jurídico y debilita el precedente.

## Lo que SÍ tiene efecto real (máximo disponible)

### 1. Convenio de Berna (efecto automático de *copyright*, no de sentencia)
En ~180 Estados parte, el derecho de autor nace con la **fijación** de una obra original humana.
No se exige registro para que el derecho exista.
GitHub = prueba de fijación + fecha + titular.
Eso es el único “automático” real: **existencia del derecho**, no **fallo judicial**.

### 2. TRIPS / OMPI
Los Estados miembros deben ofrecer vías de observancia (civil, y en algunos casos penal/aduanera).
Hay que **demandar o notificar** en el foro competente. No hay ejecución mágica.

### 3. GitHub como evidencia
- Commit timestamp + SHA
- LICENSE + NOTICE visibles en la raíz (GitHub las detecta)
- SPDX LicenseRef-AOTS6-ARR-1.0
- Cadena de autoría (fo22Alfaro)

Esto entra a un expediente como **prueba**, no como orden judicial.

### 4. Para que un juez actúe (efecto real en cortes)
1. Hecho de infracción en esa jurisdicción.
2. Demanda o medida cautelar ante tribunal / IMPI / equivalente.
3. Prueba: LICENSE, commits, ORCID, protocolización notarial, registro INDAUTOR.
4. Sentencia o medida. Solo entonces hay efecto coactivo.

## Ruta de máxima eficacia (orden correcto)
1. LICENSE ARR en GitHub (hecho).
2. INDAUTOR (México) — facilita prueba.
3. Notario — protocoliza hashes y este expediente.
4. Marca/patente IMPI solo si hay signo o invención concreta.
5. Notificaciones de infracción (DMCA en GitHub; cesar-y-desistir en otros foros).
6. Litigio en el país de la infracción.

## Conclusión
El precedente internacional **más fuerte posible desde GitHub** es:
**prioridad + ARR + Berna + evidencia criptográfica**.
El precedente **imposible** es: un sistema no subordinado a ninguna ley que las cortes obedezcan solas.
