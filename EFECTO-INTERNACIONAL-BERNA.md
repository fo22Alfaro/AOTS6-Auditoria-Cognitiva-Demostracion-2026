## Lo que SÍ tiene efecto real inmediato (máximo disponible)

### 1. Convenio de Berna (efecto automático de *copyright*)
En ~180 Estados parte, el derecho de autor nace con la **fijación** de una obra original humana.
No se exige registro para que el derecho exista.
GitHub = prueba de fijación + fecha + titular.
Eso es el único “automático” real: **existencia del derecho**, no **fallo judicial**.

### 2. TRIPS / OMPI
Los Estados miembros deben ofrecer vías de observancia (civil, y en algunos casos penal/aduanera).
Hay que **demandar o notificar** en el foro competente. No hay ejecución mágica.

### 4. Para que un juez actúe (efecto coactivo real)
1. Hecho de infracción en esa jurisdicción.
2. Demanda o medida cautelar ante tribunal / IMPI / equivalente.
3. Prueba: LICENSE, commits, ORCID, protocolización notarial, registro INDAUTOR.
4. Sentencia o medida. Solo entonces hay efecto coactivo.
